# Publication and Resume Workflow

## Recommended sequence

1. Publish this portfolio through GitHub Pages.
2. Copy the final live URL from GitHub Pages settings.
3. Add the URL to the resume header as `Portfolio: <URL>`.
4. Add the site to LinkedIn's Featured section and Contact info.
5. Upload the final Times New Roman resume PDF to the repository only if you want a public download button.

## Do not upload

- Original `.xlsm` or `.xlsx` working files
- Production VBA modules copied from an employer system
- Vendor/member names, emails, addresses, invoices, trip numbers, or item-level pricing
- Screenshots containing internal file paths or ticket URLs

## Suggested repository name

`supply-chain-automation-portfolio`

This name is clearer to recruiters than a generic repository such as `my-portfolio` and keeps the URL relevant to the target roles.

## Optional custom domain later

A custom domain is useful only after the content is stable. It is not required for applications. A GitHub Pages URL is credible and sufficient for the first version.
